# 🎮 OpenGL 3D Engines Portfolio (Desktop & Android NDK)

Welcome to the **OpenGL 3D Engine Architecture** repository. This repository showcases cross-platform 3D graphics rendering and game engine architectures written in modern C++, featuring both Desktop and Mobile (Android NDK) implementations.

---

## 📁 Repository Overview

* 🖥️ **[Desktop-Engine/](./Desktop-Engine)**: A 3D OpenGL Drone Simulator & Mini-Engine built with C++, GLFW, GLM, Assimp, and CGAL. Features 3D map imports, collision detection, and modular scene objects.
* 📱 **[Android-NDK-Engine/](./Android-NDK-Engine)**: Mobile Native C++ Engine built with Android NDK and OpenGL ES 3.0. Features multi-touch joysticks, custom shader pipeline, lighting models, and object management.

---

## 💻 Desktop Engine (`/Desktop-Engine`)
* **Tech Stack**: C++17, OpenGL 3.3+, GLFW, GLM, Assimp, CGAL.
* **Highlights**: Real-time flight simulation, OBJ mesh loading, dynamic camera, modular engine architecture.
* **Detailed Documentation**: See [Desktop Engine Documentation](./Desktop-Engine/README.md).

---

## 📱 Android NDK Engine (`/Android-NDK-Engine`)
* **Tech Stack**: C++17, Android NDK, OpenGL ES 3.0, EGL, Native Activity, Gradle.
* **Highlights**: Custom multi-touch 2D joystick overlay, dynamic lighting (Directional, Point, Spot lights), object manager, cube scenes.
* **How to Run**: Open `Android-NDK-Engine/` in Android Studio and run on an Android device or emulator.
